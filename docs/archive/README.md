# Documentos históricos

Todo lo que vive en esta carpeta es histórico y **no describe el sistema actual**.
Son planes de go-live, checklists de validación, propuestas y reportes de
incidentes anteriores a Lead Routing V3 (en producción desde 2026-09-02), varios
de ellos escritos cuando el flujo todavía usaba subastas masivas, el bot de IA
nocturno o Evolution API. Se conservan porque explican decisiones pasadas y
sirven de evidencia de auditoría, no porque sigan siendo correctos. Para el
estado real del sistema usa `README.md` en la raíz y las fuentes de verdad que
ahí se listan (contrato y plan V3 en `docs/superpowers/`,
`supabase/V3_PRODUCTION_MIGRATION_STATUS.md` y los JSON de
`whatsapp-agent/workflows/`). `reports/` contiene los reportes operativos y de
incidentes generados durante las intervenciones de agosto de 2026.
