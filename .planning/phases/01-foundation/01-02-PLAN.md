**`is_session_fresh(path: Path, max_age_hours: int) -> bool`:**
Returns True if the file exists AND its mtime is less than `max_age_hours` old. Never raises — returns False on any OS error.

**`async login(page, settings: Settings) -> None`:**
Navigates to LOGIN_URL, fills email field, fills password field (use `page.get_by_label` or `page.locator("[type=email]")` and `page.locator("[type=password]")`), clicks submit. After submit, waits for navigation. Then calls `_assert_authenticated(page)`. If assertion raises, re-raises as `AuthenticationError` with message "Login failed — check credentials or CAPTCHA". Do NOT log the password at any point.

Use randomized timing jitter between interactions:
```python
import asyncio, random
await asyncio.sleep(random.uniform(0.8, 2.5))
```
Apply jitter before filling email, before filling password, before clicking submit.

**`async _assert_authenticated(page) -> None`:**
Navigates to ACCOUNT_CHECK_URL. Waits up to 10 seconds for AUTH_INDICATOR_SELECTOR to be visible. If it times out or if the current URL contains "login" or "acceso", raises `AuthenticationError("Session invalid — redirected to login page")`.

**`async load_or_login(browser, settings: Settings) -> BrowserContext`:**
Main entry point for auth. Logic:
1. If SESSION_PATH exists and `is_session_fresh(SESSION_PATH, SESSION_MAX_AGE_HOURS)`:
   a. Create context with `storage_state=str(SESSION_PATH)`
   b. Apply stealth: `await stealth_async(page)` on a new page (then close that page)
   c. Call `_assert_authenticated(new_page)` — if raises, fall through to fresh login
   d. Close the test page. Return the context.
2. Fresh login path:
   a. Delete SESSION_PATH if it exists (stale/corrupt cleanup)
   b. Create a new context (no storage_state)
   c. Create a page, apply `await stealth_async(page)`, set a realistic user agent via `page.set_extra_http_headers`
   d. Call `await login(page, settings)`
   e. Save session: `await context.storage_state(path=str(SESSION_PATH))`
   f. Close the page. Return the context.

**`class AuthenticationError(Exception)`:** Custom exception for all auth failures.

**`async save_failure_screenshot(page, label: str) -> Path`:**
Creates SCREENSHOTS_DIR if needed. Saves screenshot to `SCREENSHOTS_DIR / f"{label}_{datetime.now().strftime('%Y%m%d_%H%M%S')}.png"`. Returns the path. Called on any auth failure before raising.

**`async async_main(args) -> int`:** Returns exit code (0 = success, 1 = failure).

Browser lifecycle — MUST use nested `async with` to guarantee cleanup even on exception:
```python
async with async_playwright() as pw:
    browser = await pw.chromium.launch(
        headless=not args.headful,
        args=["--no-sandbox", "--disable-dev-shm-usage"],
    )
    try:
        context = await load_or_login(browser, settings)
        try:
            if args.dry_run:
                logger.info("Dry run complete — session is valid")
                return 0
            # Phase 2+ will add scraper call here
            return 0
        finally:
            await context.close()
    except AuthenticationError as e:
        logger.error("Authentication failed: {}", str(e))
        return 1
    except Exception as e:
        logger.exception("Unexpected error: {}", str(e))
        return 1
    finally:
        await browser.close()
```
